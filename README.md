# Work Breakdown Structure (WBS)

## 01. النظام الأساسي Core System

### Company Management
- إدارة الشركات
- إدارة الفروع
- إدارة المصانع
- إدارة المستودعات
- إعدادات النظام
- إعدادات العملة
- إعدادات الضريبة
- إعدادات اللغة
- إعدادات المناطق

### User Management
- المستخدمين
- المجموعات
- الصلاحيات
- الأدوار
- تسجيل الدخول
- المصادقة الثنائية
- سجل العمليات

## 02. CRM

### العملاء — البيانات الأساسية
رقم العميل، الاسم، الجوال، البريد، الجنسية، الجنس، المدينة، العنوان

### البيانات الإضافية
الطول، الوزن، العمر، الملاحظات

### السجلات
سجل القياسات، سجل الطلبات، سجل الزيارات، سجل الرسائل

## 03. Appointment Management
- حجز موعد قياس
- حجز بروفة
- حجز استلام
- تقويم المواعيد
- إشعارات التذكير

## 04. Measurement Engine

### Measurement Dictionary — ثوب سعودي
Full Length, Chest, Waist, Hip, Shoulder, Neck, Sleeve Length, Armhole, Upper Arm, Cuff Width, Bottom Width

وكذلك: قميص، بنطلون، بدلة، أطفال، نسائي

### Validation Engine — أمثلة قواعد
- Hip ≥ Waist
- Armhole > Upper Arm
- Neck < Chest
- Sleeve متناسب مع الطول

### Measurement Templates
ثوب سعودي، ثوب أطفال، قميص، بنطلون، بدلة، عباية، يونيفورم

## 05. Product Configurator

### المنتجات
ثوب، قميص، بنطلون، بدلة، زي موحد

### مكونات المنتج — الثوب
- الياقة: ملكي، صيني، مربع، فرنسي
- الجيب: بدون، واحد، اثنين
- القلاب: ملكي، مفتوح، فرنسي
- الكم: سادة، كبك
- التطريز، الأزرار، القماش

## 06. Fabric Management

### أنواع الأقمشة
ياباني، كوري، إنجليزي، مصري، هندي

### خصائص القماش
العرض، الوزن، اللون، التركيب، المورد، السعر

## 07. Pattern Engine
هذه أهم ميزة في المشروع.

### Pattern Library
- Saudi Thobe: Classic, Formal, Youth
- Shirt: Regular, Slim
- Trouser: Regular, Slim

### Pattern Components
Front, Back, Sleeve, Collar, Cuff, Pocket

### Pattern Versions
V1, V2, V3

### Variation Engine
ربط: القياسات، الموديل، البترون

## 08. XML Engine

### Supported Systems
Grafis, Gerber, Lectra, Optitex, Gemini, Bullmer

### XML Export
يتضمن: القياسات، المنتج، البترون، Variation، Fabric

## 09. Sales
- Quotations: عرض سعر، تعديل، اعتماد
- Orders: طلب جديد، تعديل، إلغاء
- POS: اختيار العميل، اختيار المنتج، القياسات، السعر، الدفع

## 10. Production
- Production Orders: إنشاء أمر إنتاج، طباعة، QR
- Production Tracking — المراحل: استلام، قص، تجهيز، خياطة، تشطيب، كي، فحص، تغليف، جاهز

## 11. QR Tracking
Mobile Scan يسجل: الموظف، المرحلة، الوقت، الموقع

## 12. Quality Control
فحص القص، فحص الخياطة، فحص التشطيب، الفحص النهائي

### Defects Library
اختلاف قياس، عيب خياطة، عيب قماش، عيب كي

## 13. Warehouse
- المواد الخام: أقمشة، خيوط، أزرار، سحابات، كبك
- المنتجات: تحت الإنتاج، جاهزة
- الجرد: يومي، شهري، سنوي

## 14. Purchasing
الموردين (الأقمشة، الإكسسوارات، الخدمات)، أوامر الشراء، الاستلام، الفواتير

## 15. Accounting
دليل الحسابات، القيود اليومية، الصندوق، البنك، العملاء، الموردين، الضرائب، الأرباح والخسائر، الميزانية

## 16. ZATCA Integration
الفاتورة الإلكترونية: QR، XML، ضريبة القيمة المضافة، الإشعارات الدائنة والمدينة

## 17. Delivery Module
التسليم من الفرع، التوصيل للمنزل، المندوبين (التتبع، إثبات التسليم، التوقيع)

## 18. Messaging Center
SMS، WhatsApp، Email

### الرسائل التلقائية
تم استلام الطلب، تم الدفع، دخل الإنتاج، جاهز، خرج للتوصيل، تم التسليم

## 19. Reports
Sales, Production, Measurement, Inventory, Financial, Customer

## 20. BI Dashboard
KPIs: المبيعات، الأرباح، الإنتاج، التأخير، الجودة، المرتجعات

## 21. AI Engine
- Measurement Validation: كشف الأخطاء
- Recommendation Engine: اقتراح الموديل، القماش، المقاس
- Demand Forecast: توقع الطلب

## 22. Mobile Applications
- تطبيق العميل: الطلبات، القياسات، التوصيل، إعادة الطلب
- تطبيق الإنتاج: QR، متابعة المراحل
- تطبيق المندوب: التسليم، التوقيع

## 23. API Layer
- Public API: العملاء، الطلبات، المنتجات
- Internal API: XML، الإنتاج، المحاسبة

## 24. Security
RBAC، MFA، Audit Log، Backup، Encryption
